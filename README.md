# BritBlue Website

Official static website source for **BritBlue / British Blue Coin**.

## Pages
- `index.html` — homepage
- `about.html` — Barnaby, Jojo and Buffy
- `charity.html` — charity and transparency framework
- `roadmap.html` — project roadmap
- `litepaper.html` — website edition Litepaper
- `faq.html` — frequently asked questions

## Shared assets
- `styles.css` — responsive visual system
- `script.js` — mobile navigation and footer year

## Deployment
This is a dependency-free static site and can be hosted on GitHub Pages or any standard web host by serving the repository root.
